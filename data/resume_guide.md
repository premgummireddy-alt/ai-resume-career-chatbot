# Resume tailoring guidance
Mirror the exact keywords from the job description in your skills and bullets when you genuinely have that experience.
Start each bullet with a strong action verb and describe the result, ideally with a measurable outcome.
Keep early-career resumes to one page. Put the most relevant projects first.
Link a GitHub repository for each project so reviewers can verify the work.
Remove skills you cannot discuss confidently in an interview.
# Career guidance
For internships, emphasize coursework, projects, and tools used. Tailor a short summary to each role family.
Prepare STAR stories (Situation, Task, Action, Result) for each project on the resume.
